# L1dar Gam3

Echoes in the Dark is a browser-based LIDAR horror exploration game.

## Run

Open `index.html` with VS Code Live Server, then open the local URL in your browser. The game also works when opened directly as a local file, provided the browser allows the Three.js CDN request.

## Controls

- `WASD`: walk
- Mouse: look around; click-drag is supported when Pointer Lock is unavailable
- `Click` or `Space`: scan
- `E`: interact with terminals, relics, echoes, and the vault
- `H`: deploy or recall the recon drone
- `Q`: change scanner mode
- `R`, `B`, `G`: grenade, beacon, and flare
- `F`: use the stun weapon after buying it
- `C`: change scanner palette
